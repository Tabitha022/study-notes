>容量 `c(x, y)`
>流量 `f(x, y`

> **最大流**  
> 从源点流向汇点的最大流量
> **增广路**
> 所有边的剩余流量 $\large \ge$ `0`
>  **残留网**
>  所有剩余流量 $\large \ge$  `0` 的边以及节点构成的子图，包含正向边和反向边
>  反向边的容量 = 正向边的流量（相当于退回路径，表示这个流量我不要这么流了）

### $\large Dinic$ 求最大流
> 时间复杂度：$\large O(n m ^ 2)$
> 需要注意如果存在多测以及二分这些，每次都需要重新构图！

**步骤**
> 通过 $\large bfs$ 对点分层，找增广路
> 通过 $\large dfs$ 多路增广
>

```cpp
int dfs(int u, int mf){
	if(u == t) return mf; //走到汇点
	int sum = 0;
	while(cur[u] < G[u].size()){
		int i = cur[u];
		int v = G[u][i].to;
		int t_c = G[u][i].c;
		int t_n = G[u][i].n;
		if(t_c > 0 && d[v] == d[u] + 1){
			int x = dfs(v, min(mf - sum, t_c));
			if(x){
				G[u][i].c -= x;
				G[v][t_n].c += x;
				sum += x;
				if(sum == mf) return sum;
				
			}else{
				cur[u] ++;
				}
		}else{
			cur[u] ++;
		}
	}
	return sum;
}

		fill(cur.begin(), cur.end(), 0);
```

#### **例题**
##### [大户爱的宿舍](https://acm.hdu.edu.cn/contest/problem?cid=1238&pid=1003)

**题意**
大户要给 $\large N$ 个学生分配宿舍，一间宿舍一共有 $\large k$ 个床位，每个学生都一个长为 $\large k$ 的字符串，如果 $\large s_i = 1$ 代表这个学生愿意接受第 $\large i$ 个床位， 否则则不愿意接受
求大户最多能排满几间宿舍
$\large 1 \le N \le 1000$ 
$\large 1 \le k \le 30$

**题解**
一个有 $\large n$ 个学生，每个学生最终只会流向 $\large k$ 个床位的一个，求最终能开几件宿舍就是求流过每个宿舍的流量的最小值，每个学生的容量为 $\large 1$ 
所以我们只需要求这个最小值的最大值

### 费用流
> 最小费用最大流 ： 总花费最小的最大流
> 最大费用最大流 ： 总花费最大的最大流
> 无论是哪一种都是在最大流的情况下考虑费用，最大流的值只有一个，但是路径会有很多种

> 采用 $\large EK$ 算法

**最小费用模板**
>如果需要使用最大费用，将 $\large d$ 数初始化为 $\large -INF$ ,  然后在标注的这一行的条件
>改成 $\large if(c > 0 \ \&\& \ d[v] < d[u] + w)$
```cpp
struct edge{
	int to;
	int c;
	int w; 
	int n;
};
vector<edge> G[N];
vi d(N), mf(N), pre_v(N), pre_e(N), vis(N);
int flow = 0, cost = 0;

bool spfa(){
	fill(d.begin(), d.end(), INF); //这里也要改成 -INF
	fill(mf.begin(), mf.end(), 0);
	queue<int> q;
	q.push(s);
	d[s] = 0;
	mf[s] = INF;
	vis[s] = 1;
	while(q.size()){
		int u = q.front(); q.pop();
		vis[u] = 0；
		rep(i, 0, G[u].size() - 1){
			int v = G[u][i].to;
			int c = G[u][i].c;
			int w = G[u][i].w;
			if(c > 0 && d[v] > d[u] + w){    //这一行
				d[v] = d[u] + w;
				mf[v] = min(mf[u], c);
				pre_v[v] = u;
				pre_e[v] = i;
				if(!vis[v]){
					q.push(v);
					vis[v] = 1;
				}
			}
		}
	}
	return mf[t] > 0;
} 

void EK(){
	while(spfa()){
		int v = t;
		while(v != s){
			int u = pre_v[v];
			int i = pre_e[v];
			int nn = G[u][i].n;
			G[u][i].c -= mf[t];
			G[v][nn].c += mf[t];
			v = u;
		}
		flow += mf[t];
		cost += mf[t] * d[t];
	}
}
```
